# Asymptotic Complexity O(n)

## Objective

- Implement a Python algorithm that calculates the factorial of a number using recursion. After that, determine the asymptotic complexity O(n) of the algorithm, including an explanation of the reasoning. The goal is to evaluate how the execution time increases as a function of the input size n. 

### Exercise


- Write a Python program that:

    - Reads an integer n.

    - Calculates the factorial of n recursively.

    - Includes comments explaining each part of the code.

- Measures the algorithm's execution time for different values ​​of n:
    
    - 10, 100, 500, and 1000.

- Submit the code with the execution time results and a brief explanation of the complexity analysis.
