# Palindrome

## Objective

- Implement recursive code to check whether an array is palindrome.

### Exercise 

- Example:

    - array1 = [0, 1, 2, 3, 2, 1, 0] -> It's a palindrome

    - array2 = ["a", "b", "b", "a"] -> It's a palindrome

    - array3 = ["a", "b", "c", "b", "a"] -> It's a palindrome

    - array4 = ["a", "b", "c", "f", "b", "a"] -> It's not a palindrome
